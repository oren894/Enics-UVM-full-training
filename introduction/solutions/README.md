# Answer Keys — Local Only

These are reference solutions for every exercise under `introduction/`. They exist for you (the instructor), not the students.

**This folder must never end up on the branch students clone from.** It's meant to live only on your local `solution_branch`. Before merging anything from this branch into `main`, drop this folder from the merge.

| Assignment | Files |
|---|---|
| `Assignment_1/` | Written answers to the SV theory questions (`Questions on SV.pdf`) |
| `Assignment_2/` | Completed `01_decode_the_signal.sv`, `02_the_rendezvous.sv`, `03_generate_and_prove.sv` |
| `Assignment_3/` | Completed `case1_blocking_vs_nonblocking.sv`, `case2_priority_grant.sv` (round-robin arbiter), `case3_vault_fsm.sv` |
| `Assignment_4/` | Completed `simple_fifo.sv` |

Each `.sv` solution is the exercise file with the `INSERT YOUR CODE HERE!` sections filled in — everything else (testbenches, ports, comments) is unchanged from the exercise version, so you can drop one in place and run it directly against the same testbench to confirm it passes.
